# PEC 作为布局优化总目标的可行性分析

> **适用范围说明**：PEC 适用于存在明确内部流量、压降和泵功的强制流道阶段。当前 `04_复现方案.md` 的封闭腔三设备基准分为“静止空气导热—辐射优化”和“26 kPa自然对流二次优化”，右外壁虽使用 $h=15\,\mathrm{W/(m^2K)}$ 的外部强制风冷 Robin 条件，但模型不求外部风道压降或泵功，因此 PEC 在两个阶段都没有定义。应优先报告三个设备各自的 $T_{max}$、热桥传热、气凝胶温降、右壁排热量、总能量守恒以及两阶段最优布局差异；PEC 留到显式求解外部风道的模型使用。

> 问题：PEC（Performance Evaluation Criterion，综合换热性能评价准则）能否作为
> LT-PINN 布局优化的总目标函数？
> $$PEC = \frac{Nu}{f^{1/3}\cdot Re\cdot Pr^{1/3}}$$

---

## 1. 先拆解这个公式：PEC 到底在衡量什么

把 Colburn j 因子的定义代入：

$$j = St\cdot Pr^{2/3} = \frac{Nu}{Re\cdot Pr^{1/3}} \qquad\Longrightarrow\qquad PEC = \frac{j}{f^{1/3}}$$

这正是强化传热文献中最经典的**等泵功比较准则**（Webb & Bergles 体系）：

- **分子 j**：无量纲换热强度（归一化掉流量 Re 与物性 Pr 后的"纯换热能力"）；
- **分母 f^{1/3}**：阻力系数的立方根。因为**泵功率 ∝ f·Re³**（固定几何下），f^{1/3} 正是"等泵功"换算因子；
- **物理含义**：*消耗同样的泵功，这个布局能换来多少换热*。PEC 越大越好，PEC>1（相对基准光管 Nu₀/f₀ 形式）表示强化是值得的。

**结合"定流量"前提的一个重要化简**：你的问题是定流量（Re 固定、Pr 为空气常数），所以

$$\max\; PEC \iff \max\; \frac{Nu}{f^{1/3}}$$

此时泵功率 ∝ f（正比于压降 Δp）。PEC 的物理意义变为：**在风扇流量给定的前提下，用尽可能小的压降（风扇压头负担）换尽可能大的换热**。这与工程直觉完全一致——所以 PEC 作为评价准则是**合适且有明确物理意义的**。

---

## 2. 在 LT-PINN 框架里能不能算？—— 能，而且全部可微

PEC 作为损失项的前提是它能从网络输出中计算且对设计变量 γ 可微。逐项检查：

| 量 | 来源 | 计算方式 | 可微性 |
|---|---|---|---|
| Nu | 温度场 T(x,y;θ) | 元件表面平均：$h = \dfrac{k_f(\partial T/\partial n)_w}{T_w - T_b}$，$Nu = \dfrac{1}{A}\int hD/k_f\,dA$；壁面法向梯度用 autograd 在**边界采样点**上算（现有代码每步已生成这些点！） | ✅ ∂T/∂n 经 AD 得到，法向 n 和采样点位置都含 γ → 对 γ 可微 |
| f | 压力场 p(x,y;θ) | Fanning：$f = \dfrac{\Delta p\, D_h}{2\rho U^2 L}$，Δp 取入口/出口采样线上 p 的均值差（需要时加壁面剪切项 $\tau_w = \mu(\partial u/\partial n)_w$） | ✅ p 是网络输出，入口/出口点固定 → 对 θ、γ 可微 |
| Re, Pr | 常数 | 定流量给定 | — |

**结论：PEC 可以作为损失项嵌入 LT-PINN 的总损失**，实现上没有障碍（框架的可微性红利）。

但"能算"不等于"适合直接当总目标"。下面给出四个必须注意的坑。

---

## 3. 把 PEC 直接当总目标的四个坑

### 坑 1：比值型目标的梯度病态

PEC 是分式，f 在分母且带 1/3 次幂：

$$\frac{\partial\, PEC}{\partial\gamma} \propto \frac{1}{f^{1/3}}\frac{\partial Nu}{\partial\gamma} - \frac{Nu}{3f^{4/3}}\frac{\partial f}{\partial\gamma}$$

当某个布局使 f 很小时，第二项梯度爆炸；Adam 遇到这种损失面会震荡。**解决方案很简单——取对数**：

$$\max\; \ln PEC \iff \min\; L_{obj} = \tfrac{1}{3}\ln f - \ln Nu$$

对数把比值变成差值，两项梯度量级始终 O(1)，且单调性不变（最优解完全相同）。**如果要用 PEC，就用它的对数形式。**

### 坑 2：全局标量 → 信用分配（credit assignment）问题

PEC 是整个流道的**一个标量**。布局优化有 2K~3K 个设计变量（K 个元件的位置/角度），一个标量损失反传回去，每个 γ_k 分到的梯度信号很弱且互相纠缠——"Nu 提高了，是哪个元件的功劳？"PINN 不知道。

**缓解**：把目标分解到元件级——

$$L_{obj} = \frac{1}{3}\ln f - \sum_{k=1}^{K} w_k \ln Nu_k$$

每个元件自己的 Nu_k（用各自的边界点计算）给各自的 γ_k 提供直接梯度信号，f 仍用全局量。这与 LT-PINN 论文中拓扑损失按 patch 对分解的思想一致。

### 坑 3：PEC 看不见热点 —— 对电子设备这是致命的

PEC 是**平均量**。完全可能存在这样的布局：平均 Nu 很高、压降很低（PEC 漂亮），但某个被上游元件完全遮挡的元件处于死水区，局部温度超过结温上限烧毁。**电子散热的第一约束是 T_max ≤ 结温，而不是平均换热效率。**

所以 PEC **不能单独**作为目标，至少要叠加热点惩罚：

$$L_{obj} = \underbrace{\tfrac{1}{3}\ln f - \ln Nu}_{\text{效率项}} + \underbrace{\lambda_h\,\mathrm{ReLU}(T_{max}^{lse} - T_{limit})}_{\text{热点硬约束}}$$

其中 $T_{max}^{lse} = \frac{1}{\alpha}\ln\sum_i e^{\alpha T_i}$（log-sum-exp，可微的 max 近似，α 取 10–50）。

### 坑 4：定义口径的敏感性

Nu 和 f 的定义口径会显著改变 PEC 数值甚至排序：

- **特征长度**：用元件尺寸、水力直径 D_h 还是流道长度？
- **参考温度**：T_b 用入口温度、截面体平均（bulk）温度还是对数平均温差？
- **f 的定义**：Fanning 还是 Darcy（差 4 倍，经 1/3 次幂后差 1.59 倍）；
- **换热面积**：只算元件表面，还是连流道壁面一起算？

**建议**：口径一旦选定就在所有候选布局间保持一致（PEC 本来就比较"相对值"）；并在文档中明确记录。

---

## 4. 推荐的目标函数体系（分三层）

对于未来显式求解外部强制流道的扩展，可按以下方式组织；当前封闭腔阶段 A/B 的目标定义以 `04_复现方案.md` 为准：

```text
第一层：主目标（二选一）
  方案 a（PEC 派）:  L_obj = (1/3)·ln f − Σ_k w_k·ln Nu_k        ← 等泵功效率
  方案 b（温度派）:  L_obj = w1·T_max^lse + w2·T̄_元件             ← 直接面向可靠性

第二层：约束惩罚
  L_hot  = λ_h·ReLU(T_max^lse − T_limit)      热点硬约束
  L_t    = Σ_{i<j} 1/r_ij²                    元件防重叠（论文 Eq.12）
  L_wall = Σ_k ReLU(d_min − d(γ_k, 机箱壁))²   禁布区/贴壁约束

第三层：监控指标（不进损失，只记录，类似现有代码的 monitor_test）
  PEC、Nu_平均、Δp、T_max 精确值、各元件 Nu_k 分布
```

**我的建议**：优化主目标用**方案 b（温度派）**——因为它直接对应电子设备的设计要求，且温度是逐点场量、梯度信号天然分解到各元件；**PEC 放在第三层做监控与最终方案比选**。如果研究目标本身是"探索效率最优布局"（偏传热强化机理研究），则用方案 a + 热点惩罚。

两者并不矛盾：训练时按温度优化，报结果时用 PEC 排序——这正是传热强化文献的通行做法。

## 5. 你列的四个文献因素在框架中的落点

| 文献因素 | 物理本质 | 在 LT-PINN 改造方案中的对应 |
|---|---|---|
| 表面热流分布（设备产热） | 各元件 q̇ 不同且可能非均匀 | 每个 patch 带独立热源参数 q̇_k（可作已知量，也可作设计变量）；元件内热传导 ∇²T + q̇/k = 0 写入 PDE 损失（圆内掩码 1−δ） |
| 与来流夹角（布局绝对位置） | 迎流角度改变局部 h 分布 | **给 γ 增加旋转角参数 θ_k**，patch 用矩形/椭圆（论文 3.2 的分段直线矩形基元正好可用）；夹角效应由流场耦合自动体现 |
| 入口距离 | 来流边界层发展程度不同，入口段 h 高 | γ 的 x 坐标即此变量；入口段换热增强由能量方程 + 速度场发展自然捕捉 |
| 相互遮挡（布局相对位置） | 尾迹/死水区使下游元件 h 骤降 | **只有路线 A（流热耦合）能表达**——遮挡本质是流场速度分布改变，固定 h 的路线 B 完全看不到遮挡效应 |

> 最后一点是选择路线 A 的最强论据：**你列的四个因素里有三个（夹角、入口距离、遮挡）都通过流场起作用**。如果用固定换热系数 h 的解耦路线 B，这些因素全部丢失，布局优化会退化成一个没有物理依据的几何游戏。PEC 作为目标也就失去了评估基础——Nu 和 f 都必须从耦合解里出来才可信。

## 6. 代码实现草图（路线 A 完成后加入）

```python
class PECLoss(torch.nn.Module):
    """监控/目标两用：返回对数PEC目标 + 各分项指标"""
    def __init__(self, nn_fun, D_h, L_ch, Re, Pr, rho=1.0, k_f=1.0):
        super().__init__()
        self.fun = nn_fun; self.D_h = D_h; self.L = L_ch
        self.Re = Re; self.Pr = Pr; self.rho = rho; self.k_f = k_f

    def forward(self, X_surf, X_in, X_out):
        # --- Nu：元件表面平均换热 ---
        x, y = X_surf[:,0:1], X_surf[:,1:2]
        T = self.fun(X_surf)[:,3:4]                       # 第4通道温度
        T_x = torch.autograd.grad(T, x, torch.ones_like(T), create_graph=True)[0]
        T_y = torch.autograd.grad(T, y, torch.ones_like(T), create_graph=True)[0]
        nx, ny = 法向分量(X_surf, γ)                       # 由当前 γ 解析计算
        dT_dn = T_x*nx + T_y*ny
        h  = self.k_f * dT_dn / (T - T_bulk)              # T_bulk 由入口/截面平均给定
        Nu = (h * self.D_h / self.k_f).mean()

        # --- f：出入口压差 ---
        p_in  = self.fun(X_in )[:,2:3].mean()
        p_out = self.fun(X_out)[:,2:3].mean()
        U = 1.0                                            # 归一化来流
        f = (p_in - p_out) * self.D_h / (2*self.rho*U**2*self.L)

        # --- 对数PEC目标（minimize） ---
        L_obj = f.clamp_min(1e-8).log()/3 - Nu.clamp_min(1e-8).log()
        PEC   = Nu / (f**(1/3) * self.Re * self.Pr**(1/3))  # 监控量
        return L_obj, PEC.detach(), Nu.detach(), f.detach()
```

要点：`clamp_min` 防 log(0)；`detach()` 的量只记录不反传；法向由 γ 解析求得（LT-PINN 显式边界的红利——密度法 PINN 在这里就卡住了）。

---

## 7. 结论

1. **PEC 物理意义正确**（等泵功换热效率），定流量下化简为 max Nu/f^{1/3}，与你的问题匹配，**适合作为总评价准则**；
2. **技术上可嵌入 LT-PINN**：Nu（壁面 ∇T·n）与 f（Δp）都能从网络输出可微计算；
3. **但不建议原样作为唯一优化目标**：需做对数变换（治病态梯度）、按元件分解 Nu_k（治信用分配）、叠加 T_max 热点硬约束（补平均量盲区）；
4. **推荐用法**：主目标用温度派目标（T_max^lse + T̄），PEC 作为监控指标与方案比选准则——优化按温度走，验收按 PEC 排；
5. **前提是路线 A（流热耦合）**：遮挡、夹角、入口距离三个因素都由流场决定，固定 h 的解耦模型下 PEC 没有意义。
