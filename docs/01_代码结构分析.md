## 0. 论文动机：LT-PINN 旨在解决什么问题

### 0.1 大背景：拓扑优化的计算困境

拓扑优化的目标是：在给定设计空间内，自动找到满足性能指标与边界约束的**最优材料/几何布局**。它在航空航天、汽车、能源、生物工程等领域有广泛应用，但经典方法（如密度法 SIMP、水平集法）存在两个痛点：

1. **计算昂贵**：每次设计迭代都要重新求解一次物理场（有限元），大型问题涉及数百万设计变量、数百次迭代；
2. **依赖网格**：拓扑/形状剧烈变化时需要反复重网格或自适应网格，几何细节捕捉能力受网格束缚。

### 0.2 现有 PINN 方案（密度法 DT-PINN）的三个缺陷

PINN 把物理方程直接编码进神经网络，天然**无网格**，且能"一次训练同时得到拓扑 + 物理场解"，是拓扑优化的理想载体。但既有的 PINN 拓扑优化方案（论文称 **DT-PINN**，density topology-oriented PINN）全部基于**密度描述**（介电常数图、密度场、固相分数等），存在本质缺陷：

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | **拓扑是隐式的**：网络输出的密度 ρ 是连续光滑函数，只是理想 0/1 示性函数的近似 | 训练后必须**人工选阈值** ρ* 插值提取边界，结果对阈值极其敏感；边界模糊，阻碍工程理解与制造复现 |
| 2 | **边界位置训练完成前未知** | **无法精确施加边界条件**——尤其是需要边界法向的 Neumann 条件（论文 Eq. 5 的复合 PDE 损失只能间接、近似地塞入 Dirichlet 条件），导致物理场解精度差（论文实测热流误差是 LT-PINN 的 174 倍） |
| 3 | **边界法向无法重建** | 模糊边界没有良定义的法向量，无法支撑通量类约束与后续 CAD 建模 |

此前改善密度法的修补手段（幂次缩放、sigmoid 变换、Fourier 映射、Eikonal 正则、高斯插值等）都只是在"锐化"一个本质上连续的表示，仍需要繁复的人工调参。

### 0.3 LT-PINN 的解决思路与目标问题

LT-PINN 把经典显式拓扑优化中的 **Lagrangian 拓扑描述**（MMC/MMB 思想：用一组简单、可重叠、可参数化的 patch 组合出复杂拓扑）首次引入 PINN 框架，**把拓扑边界曲线的控制参数 γ（如圆心）直接作为网络的可学习参数**。由此针对性地解决：

- **问题 1 → 显式边界**：每步训练中边界由 $F_\gamma(\mathbf{x})=0$ 显式给出，无需人工阈值插值；
- **问题 2 → 精确边界条件**：边界位置每步已知，Dirichlet 与 Neumann 条件都通过专用边界损失 $L_b$ 精确施加；
- **问题 3 → 法向解析可得**：$\mathbf{n}=\nabla F_\gamma/\|\nabla F_\gamma\|$ 有解析表达式；
- **附加能力 → 复杂拓扑结构先验**：多 patch 之间的间距/防重叠通过拓扑损失 $L_t$ 编码（自相似、周期性结构）。

由此，LT-PINN 面向的**目标问题类型**（论文各算例覆盖）可归纳为：

| 问题类型 | 论文算例 | 有无测量数据 |
|---|---|---|
| **隐藏拓扑识别（逆问题）**：由稀疏场测量反演未知边界位置/形状 + 重建全场 | 3.1 单圆（弹性 Dirichlet / Laplace Neumann）、3.2 三角/矩形/凹砖基元 | 有（稀疏，<1%） |
| **复杂多体拓扑识别**：多圆阵列（2/3/8 圆）的流场联合反演 | 3.3 定常流（Re=1）与非定常流（Re=100，压力 Poisson） | 仅 ROI 边缘数据 |
| **目标驱动的拓扑生成（正问题/设计）**：无任何测量数据，按目标出口速度剖面生成拓扑 | 3.4 流体重排（48 圆聚团，均匀来流 → 正弦出流） | 无 |

论文宣称的四大创新（结论部分）：(1) 免人工边界插值；(2) 任意边界条件的精确编码（热流相对 L2 误差比 DT-PINN 降 99.42%，弹性位移误差降 66.53%）；(3) 拓扑损失处理自相似复杂结构；(4) 生成结果可直接转 CAD/CFD，具备制造兼容性。

### 0.4 整个优化过程（方法框架）

LT-PINN 把"解 PDE"与"找拓扑"统一成**一次联合训练**（而非经典方法的"迭代求解-灵敏度分析-更新设计"循环）：

```text
输入:  PDE 控制方程 N_ω*[u] = f
       + 稀疏测量数据 u*（可无）
       + 边界条件 B（Dirichlet / Neumann / 任意）
       + 先验: 随机散布的参数化拓扑 patch（边界曲线族 F_γ = 0）

初始化:
  θ ← He 初始化（FNN 权重）
  γ ← 随机初始化，sigmoid 归一化铺满 ROI

联合训练（随机梯度下降, Adam）—— 每步:
  ① 由当前 γ 解析得到边界 F_γ(x)=0、法向 n=∇F_γ/‖∇F_γ‖、
     以及几何距离函数 δ(x,γ) = 1/(1+e^(−β·SDF))
  ② 前向: FNN(x; θ) → 物理场 u
  ③ 组装总损失（Eq. 13）:
       L_p = Σ [Π_k δᵏ(x,γ)]²·R²     PDE 残差只在拓扑外施加
       L_b = Σ (B[u] − g)²           边界条件（采样点随 γ 每步重新生成）
       L_d = Σ (u − u*)²             稀疏数据（可无）
       L_t = L_t¹ + L_t²             patch 间距/防重叠约束（可无）
  ④ 反向传播同时得到 ∂L/∂θ 与 ∂L/∂γ（Eq. 14），同步更新场与拓扑
  ⑤ γ 轨迹稳定 → 可早停

输出:  最优拓扑（γ 显式给出边界，直接可转 CAD）
       + 全场 PDE 解 u(x)
```

**与经典拓扑优化的本质区别**：经典方法是"外层设计迭代 × 内层有限元求解"的嵌套循环；LT-PINN 把设计变量 γ 降维成与网络权重 θ 并列的少量可训练参数，**一次梯度下降过程同时收敛到场解与拓扑**——这既是效率来源，也是"无网格捕捉几何细节"能力的来源。

**适用边界（论文明确指出）**：LT-PINN 需要关于边界曲线族 $F_\gamma$ 的先验（圆、分段直线多边形等）；若完全无拓扑先验，则密度法 DT-PINN 更合适——两者位于拓扑优化谱系的两端：DT-PINN 重灵活性，LT-PINN 重精度与可制造性。

## 2. 各模块详解

### 2.1 `NeuralNetwork.py` —— 网络结构

```text
MyNet(numIN=2, numOUT=1, numHidden=256, numLayer=4, numCenter=1)
```

包含**两部分参数**：

**(a) 物理场近似网络（FNN）**

```text
输入 (x, y) ∈ R²
  → Linear(2, 256)   + tanh      # IN
  → Linear(256, 256) + tanh ×7   # FC0 … FC6（实际为 8 层隐藏层，与论文 Table 3 的 8 层一致）
  → Linear(256, 1)                # OUT，输出温度 T
```

- 激活函数：`tanh`（保证二阶导数存在且光滑，满足 Laplace 方程对 u_xx、u_yy 的需求）
- 输出维度 `numOUT=1`：仅温度场 T（归一化，数据加载时减去 273K）

**(b) 可学习几何参数 γ（Lagrangian 拓扑参数）**

```python
self.X_center = nn.Linear(1, numCenter, bias=False)  # 圆心 x 坐标（标量权重）
self.Y_center = nn.Linear(1, numCenter, bias=False)  # 圆心 y 坐标（标量权重）
```

- 用两个 `1×1` 无偏置线性层的**权重本身**作为可训练参数，即 γ = (X_center, Y_center)。
- 这是 LT-PINN 的核心：拓扑边界曲线 F_γ(x) = (x−γ)² − 0.5² = 0 的控制参数直接参与梯度下降。
- 在 `main.py` 与 `loss.py` 中通过 sigmoid 重参数化把圆心约束在 ROI 内：

$$
\gamma_x = (L_{x,\max}-L_{x,\min}+2)\cdot\sigma(w_x) + (L_{x,\min}-1)
$$

### 2.2 `loss.py` —— 损失函数（论文 Eq. (11) 的实现）

| 类 | 对应论文公式 | 功能 |
|---|---|---|
| `PDELoss` | Eq. (6)/(7)/(11) 之 L_p | Laplace 残差 `u_xx + u_yy`，乘以几何距离掩码 δ |
| `BCLoss`  | Eq. (9)/(10)/(11) 之 L_b | Neumann 边界条件 ∇T·n = q（q = −0.5） |
| `DataLoss`| Eq. (11) 之 L_d | 稀疏温度监督数据的 MSE + 相对 L2 误差监控 |

**PDELoss 的关键实现**（几何距离函数 δ 掩码）：

```python
dist = sqrt((x - X_center)**2 + (y - Y_center)**2)   # 点到圆心距离
mask = 1 / (1 + exp(-k * (dist - radius)))           # δ，k=100=β，radius=0.5
eq1  = mask * (u_xx + u_yy)                          # 只在圆外（流体/介质域）施加 PDE
loss = sum(eq1**2)                                   # 论文为 mean，代码用 sum
```

- 圆内 δ→0（不施加 PDE），圆外 δ→1，边界上 δ=0.5 —— 即论文 Fig. 3 的 sigmoid-SDF 构造。
- `dist` 依赖可学习参数 γ，因此 **PDE 损失对 γ 可微**，梯度经 `mask` 反传推动圆心移动（论文 Eq. (14)）。

**BCLoss 的关键实现**（Neumann 边界）：

```python
# 边界采样点上：r0 = u_x*(x-X_center) + u_y*(y-Y_center) + 0.5
# 即 ∇T·(x−γ) = −0.5；圆半径 0.5 时 n = (x−γ)/0.5，‖∇F_γ‖=1，
# 所以该项 = ∇T·n − q，q = −0.5（论文 Section 3.1.2 的热源设定）
```

- 注意 `u_x` 对 (x−X_center) 也可微，γ 同时从边界法向的定义中获得梯度。

**DataLoss**：返回 `(MSE_sum/N, 相对L2误差)`，后者只用于监控不参与反传。

### 2.3 `main.py` —— 数据准备与训练循环

**数据划分**（数据文件 `heat_128x128.csv`，本算例 Lx/Ly 上下限均为 0，即 ROI = [−1,1]² 核心区 + 0.1 外延环带）：

| 点集 | 选取方式 | 用途 |
|---|---|---|
| `x_all/y_all` | ROI（[−1.1, 1.1]²）内全部网格点 | 总数据池 |
| `X_test/Y_test` | 核心区 [−1,1]² 内全部点 | 测试监控（不算梯度） |
| `X_sup/Y_sup` | 从核心区随机抽 10% | 稀疏监督数据（L_d） |
| `X_internal` | [−1,1]² 上 120×120 均匀网格，`requires_grad=True` | PDE 配点（L_p） |
| `X_bc`（每步生成） | 4 个同心圆环（r=0.5,0.4,0.3,0.2）× 256 点 = 1024 点 | Neumann 边界损失（L_b） |

> 边界点围绕**当前预测的圆心**动态生成（`get_circle_points(X_center, Y_center)`），
> 因此每一步边界条件都施加在"当前拓扑边界"上 —— 这是 LT-PINN 与 DT-PINN 的本质区别。

**训练循环**（Adam，lr=1e−4，400,000 epochs）：

```text
for epoch in 1..400000:
    1. γ ← sigmoid 重参数化得到当前圆心
    2. loss_sup = 1e4 · DataLoss(X_sup)         → backward   # λ_d = 1e4
    3. X_bc ← 以当前圆心生成 1024 个边界点
       loss_bc  = 1.0 · BCLoss(X_bc)                          # λ_b = 1
       loss_eq  = 1.0 · PDELoss(X_internal)                   # λ_p = 1
       (loss_bc + loss_eq).backward()
    4. no_grad 下计算测试集相对 L2 误差（监控）
    5. optimizer.step() → zero_grad()
    6. 每 1000 步写 loss_log.csv 并保存 nn_fun_params / opt_params
       每 100000 步额外存档带步数后缀的断点
```

损失权重与论文 Table 3 一致：λ_d=1e4，λ_p=1，λ_b=1（单 patch 不使用拓扑损失 λ_t）。
拓扑损失 `loss_tp = (Y_center)²` 在代码中被注释掉（论文中 Lt 仅用于多圆阵列算例）。

**从 `checkpoint/loss_log.csv` 可见训练收敛**：400k 步后总损失从 ~139 降到 ~0.11，
相对 L2 误差从 ~1.3% 降到 ~0.27%（与论文 Table 4 的 0.0027 一致），
圆心收敛到 ≈ (−0.002, −0.0019)，即正确识别出位于原点的圆形热源。

## 3. 模型 Pipeline 总结

```text
                    ┌─────────────────────────────────────────────┐
                    │              离线参考数据 (Star-CCM+)         │
                    │        heat_128x128.csv: (x, y, T)           │
                    └──────────────┬──────────────────────────────┘
                                   │
        ┌──────────────────────────┼───────────────────────────────┐
        ▼                          ▼                               ▼
  稀疏监督点 X_sup            PDE 配点 X_internal             测试点 X_test
  (10% 随机抽样)              (120×120 均匀网格)               (仅监控)
        │                          │
        ▼                          ▼
┌───────────────────────────────────────────────────────────────┐
│                        MyNet (θ, γ)                            │
│  FNN: (x,y) → T(x,y; θ)      γ = (X_c, Y_c) 可学习圆心          │
└───────┬──────────────────┬───────────────────┬────────────────┘
        │                  │                   │
        ▼                  ▼                   ▼
  L_d 数据损失        L_p PDE 损失          L_b 边界损失
  (T_pred − T*)²      δ(x,γ)·(T_xx+T_yy)    在 r=0.5 圆环上:
        │             δ = sigmoid(β(dist−r))  ∇T·(x−γ) + 0.5
        │                  │                   │
        └──────────┬───────┴───────┬───────────┘
                   ▼               ▼
            L_tot = 1e4·L_d + L_p + L_b
                   │
        ┌──────────┴──────────┐
        ▼                     ▼
  ∂L/∂θ → 更新网络权重   ∂L/∂γ → 更新圆心（经 δ 掩码与法向两个通路）
        │                     │
        └──────────┬──────────┘
                   ▼
     输出: 重建温度场 T(x,y) + 显式拓扑边界 F_γ(x)=0（圆心 γ）
```

**核心机制一句话**：PDE 在圆外通过 sigmoid-SDF 掩码 δ 施加、Neumann 通量边界条件在当前估计的圆形边界上施加，两者都对几何参数 γ 可微，因此训练过程中"温度场重建"与"热源定位"被同一个损失联合驱动，无需任何手工阈值插值。
