## 知识点 1：PINN 基本范式与自动微分

**论文位置**：Section 2.1，Eq. (1)–(4)
**代码位置**：[`src/loss.py`](../src/loss.py) `PDELoss.forward`

论文把任意 PDE 写作 $\mathcal{N}_\omega[\mathbf{u}(\mathbf{x},t)] = f(\mathbf{x},t)$，PINN 用网络 $\mathbf{u}(\mathbf{x};\theta)$ 近似解，残差
$R = \mathcal{N}_{\omega^*}[\mathbf{u}] - f$ 经**自动微分**（AD）计算，作为损失 $L_p = \frac{1}{N}\sum R_i^2$。

代码中：

```python
u_x  = torch.autograd.grad(u,  x, ..., create_graph=True)[0]
u_xx = torch.autograd.grad(u_x, x, ..., create_graph=True)[0]
eq1  = u_xx + u_yy        # Laplace 残差 R
```

**数学补充**：
- **自动微分（AD）**：对计算图应用链式法则。`create_graph=True` 让一阶导本身也在计算图中，从而可再求二阶导。AD 给出的是**逐点精确导数**（相对数值差分无截断误差），但代价是显存随求导阶数增长。
- **Laplace 算子**：$\nabla^2 T = \partial_{xx}T + \partial_{yy}T$，稳态无内热源热传导的控制方程。椭圆型 PDE，解的性态完全由边界条件决定 → 这也是为什么本算例中边界损失如此关键。
- **激活函数选择 tanh**：要求 $\tanh \in C^\infty$ 且二阶导不恒为零；ReLU 的二阶导几乎处处为 0，不能用于二阶 PDE。

## 知识点 2：密度法拓扑描述（DT-PINN，基准方法）

**论文位置**：Section 2.1，Eq. (2)–(5)
**代码位置**：本仓库未实现（基准对比方法）；论文 Eq. (5) 的复合 PDE 损失可作为对照理解 `PDELoss` 的设计动机。

密度函数 $\rho$ 理想上是 0/1 的示性函数（Dirac delta 型），PDE 改写为

$$(1-\rho)\big(\mathcal{N}_{\omega^*}[\mathbf{u}] - f\big) = 0$$

由于网络输出必然光滑，$\rho$ 实际是快速衰减的**广义水平集函数**，边界要靠人工选阈值 $\rho^*$ 提取；且训练完成前边界位置未知，Neumann 条件（需要法向）无法施加。

**数学补充**：
- **水平集方法（level-set）**：用符号距离函数 $\phi$ 的零等值面 $\phi=0$ 表示边界；$\rho = H(\phi)$（Heaviside）。密度法与水平集本质同源。
- **Gibbs 振荡**：用光滑基（神经网络/傅里叶）逼近间断函数时在间断附近产生振荡（论文 Appendix B 与 Fig. B.2 误差集中在边界附近的原因）。

## 知识点 3：Lagrangian 拓扑描述 + 符号距离函数（SDF）—— 本文核心

**论文位置**：Section 2.2，Eq. (6)–(8)，Fig. 3
**代码位置**：
- [`src/NeuralNetwork.py`](../src/NeuralNetwork.py) — `X_center/Y_center` 两个 `Linear(1,1)` 层，其权重即几何参数 $\gamma$
- [`src/loss.py`](../src/loss.py) `PDELoss` 中的 `dist`、`mask`
- [`src/main.py`](../src/main.py) — sigmoid 重参数化

核心思想：把拓扑边界曲线 $F_\gamma(\mathbf{x}) = 0$ 的**控制参数 γ 直接作为可学习参数**（对圆形 patch，γ 就是圆心）。边界到 PDE 的映射通过几何距离函数：

$$\delta(\mathbf{x},\gamma) = \frac{1}{1+e^{-\beta\,\mathrm{SDF}}}, \qquad \mathrm{SDF} = \mathrm{sign}(\mathbf{x})\cdot\|\mathbf{x} - \mathbf{x}^*_{\partial\Omega_1}\|_2$$

圆形 patch（直径 1）：$F_\gamma(\mathbf{x}) = (\mathbf{x}-\gamma)^2 - 0.5^2 = 0$，$\delta = \dfrac{1}{1+e^{-\beta(\|\mathbf{x}-\gamma\|_2 - 0.5)}}$。

代码实现（逐行对应）：

```python
dist = torch.sqrt((x - X_center)**2 + (y - Y_center)**2)   # |SDF|，圆外为正
mask = 1 / (1 + torch.exp(-k * (dist - radius)))           # δ，k=100 即论文 β=100
eq1  = mask * eq1                                          # (Π δᵏ)·R，单 patch n=1
```

多 patch 时取乘积 $\prod_k \delta^k$：任一点落在任一 patch 内即屏蔽 PDE。

**γ 的 ROI 约束**（论文 Section 3 末段）：γ 随机初始化后用 sigmoid 归一化到感兴趣区域：

```python
X_center = (Lx_max-Lx_min+2)*torch.sigmoid(nn_fun.X_center.weight[0,0]) + (Lx_min-1)
```

**数学补充**：
- **符号距离函数（SDF）**：$d(\mathbf{x},\Gamma) = \min_{\mathbf{x}^*\in\Gamma}\|\mathbf{x}-\mathbf{x}^*\|_2$，配合内外符号。SDF 满足 Eikonal 方程 $|\nabla\phi|=1$（几乎处处），其梯度即边界法向。
- **sigmoid 锐化**：$\beta$ 控制过渡带宽度 $\sim O(1/\beta)$；$\beta=100$、半径 0.5 时过渡带约 ±0.05，近似清晰界面。边界上 $\delta=0.5$，保证边界点处 PDE 残差仍有一半权重，避免边界处约束完全消失。
- **MMC/MMV 思想**（论文引 [33][34]）：用一组可移动、可重叠的简单参数化 patch 组合出复杂拓扑，是经典显式拓扑优化方法；LT-PINN 将其搬进无网格 PINN 框架，省去了传统 MMC 所需的自适应重网格。

## 知识点 4：边界条件损失——Neumann 条件的精确施加

**论文位置**：Section 2.2，Eq. (9)–(11)；算例 Section 3.1.2，Eq. (18)
**代码位置**：[`src/loss.py`](../src/loss.py) `BCLoss`；[`src/main.py`](../src/main.py) `get_circle_points`

Neumann 条件需要边界法向：

$$\mathbf{n} = \frac{\nabla F_\gamma}{\|\nabla F_\gamma\|_2}, \qquad \mathcal{B}:\ \nabla\mathbf{u}\cdot\mathbf{n} = q$$

对圆 $F_\gamma = (\mathbf{x}-\gamma)^2 - r^2$，$\nabla F_\gamma = 2(\mathbf{x}-\gamma)$，在 $r=0.5$ 上 $\|\nabla F_\gamma\|=1$，故 $\nabla T \cdot \mathbf{n} = \nabla T\cdot(\mathbf{x}-\gamma)$。

代码：

```python
r0 = u_x*(x - X_center) + u_y*(y - Y_center) + 0.5   # ∇T·n − q，q = −0.5
output = sum(r0²)/N_b
```

边界点每步围绕**当前圆心**重新采样（4 个同心环 r=0.5/0.4/0.3/0.2 × 256 点 = 1024 点），把条件施加在边界及其内侧邻域，增强鲁棒性。

**数学补充**：
- **Fourier 热传导定律**：$\mathbf{q} = -k\nabla T$，Neumann 条件 $\nabla T\cdot\mathbf{n} = q$ 物理上即给定边界热流。$q=-0.5<0$ 表示温度梯度与外向法向反向 → 边界温度高于外部 → 圆形 patch 是**热源**（这正是电子元件发热的数学抽象！）。
- **三类边界条件**：Dirichlet（给值 $u=u_b^*$）、Neumann（给法向通量）、Robin（两者线性组合 $au + b\,\partial_n u = g$，对流换热的标准模型，见文档 03）。
- **为什么 DT-PINN 做不到**：Eq. (10) 需要 $\nabla F_\gamma$，而密度法的边界训练前未知，无法采样边界点、无法定义法向。

## 知识点 5：几何参数 γ 的联合优化（联合反问题）

**论文位置**：Eq. (13)–(14)
**代码位置**：[`src/main.py`](../src/main.py) 训练循环 + `loss.py` 中 mask/法向对 γ 的依赖

总损失 $L_{tot}(\theta,\gamma) = \lambda_p L_p + \lambda_b L_b + \lambda_d L_d + \lambda_t L_t$，
γ 的更新（论文 Eq. 14）：

$$\gamma^{l+1} = \gamma^{l} - \eta\Big(\lambda_p \tfrac{\partial L_p}{\partial\gamma} + \lambda_b\tfrac{\partial L_b}{\partial\gamma}\Big)$$

代码中无需手写这两个偏导——γ 注册为 `nn.Parameter`（Linear 层权重），PyTorch autograd 沿两条通路自动反传：
1. **PDE 通路**：`mask` 含 `dist(γ)` → $\partial L_p/\partial\gamma$；
2. **边界通路**：`BCLoss` 中法向 $(x-\gamma)$ 与采样点坐标都含 γ → $\partial L_b/\partial\gamma$。

**数学补充**：
- 这是一个**双变量联合优化**：θ（函数空间近似）与 γ（有限维几何参数）。γ 维度极低（单圆仅 2 维），其梯度信号强、收敛快（`loss_log.csv` 显示圆心几千步内即接近真值，与论文 Fig. 13 的 γ 轨迹一致，~50k 步稳定）。
- **早停判据**：γ 稳定即可停（论文 3.3.1 节），这是显式参数化独有的便利。
- **sigmoid 重参数化**属于**边界约束的变量替换法**：无约束优化 $w\in\mathbb{R}$ 等价于约束优化 $\gamma\in\text{ROI}$，避免投影梯度。

## 知识点 6：拓扑损失（多 patch 几何约束）

**论文位置**：Eq. (12)–(13)；算例 Section 3.3（2/3/8 圆阵列）、Section 3.4（48 圆流体重排）
**代码位置**：`main.py` 中被注释的 `loss_tp = wTp*(Y_center)**2`（本单圆算例未启用；论文多圆算例使用）

$$L_t^1 = \frac{1}{N}\sum_i\sum_{j\ne i}(r_{ij} - r_{ij}^*)^2 \quad(\text{固定间距约束});\qquad
L_t^2 = \frac{1}{N}\sum_i\sum_{j\ne i}\frac{1}{r_{ij}^2} \quad(\text{防重叠约束})$$

**数学补充**：
- $L_t^2$ 是**斥力势**（类 Lennard-Jones 短程排斥），$r_{ij}\to 0$ 时发散，阻止 patch 重叠。
- 这类先验约束把"自相似/周期性"结构知识编码进损失，缩小搜索空间、避免局部极小。

## 知识点 7：控制方程家族（论文各算例）

| 算例 | 方程 | 边界 | 代码对应 |
|---|---|---|---|
| 3.1.1 弹性力学 | $\nabla\cdot\boldsymbol\sigma=0$ + 本构 Eq.(16)(17) | Dirichlet $\u|_{bc}=0$ | 未含（结构同构：多输出 + 二阶导） |
| 3.1.2 Laplace 热传导 | $\nabla^2 T = 0$ | Neumann $\nabla T\cdot n = -0.5$ | ✅ **本仓库** |
| 3.2 多边形基元 | $\nabla^2 T = 0$，分段直线 $F_\gamma$（Eq. 20–22） | Dirichlet $T\|_{bc}=1$ | 未含（需把 SDF 换成分段直线距离） |
| 3.3.1 定常流 | 不可压 NS Eq. (23)，Re=1 | 无滑移 $u\|_{bc}=0$ | 未含（`visualize.py` 残留 3 输出结构） |
| 3.3.2 非定常流 | 压力 Poisson Eq. (25)，Re=100 | 无滑移 | 未含 |
| 3.4 流体重排 | 同 Eq. (23) + 出口目标剖面作数据损失 | 目标驱动 | 未含（48 patch） |

**数学补充（NS 方程）**：不可压 Navier–Stokes
$\nabla\cdot\mathbf{u}=0$，$(\mathbf{u}\cdot\nabla)\mathbf{u} = -\nabla p + \frac{1}{Re}\nabla^2\mathbf{u}$。
压力 Poisson 方程由对动量方程取散度并利用连续性得到：$\nabla^2 p = -\nabla\cdot(\mathbf{u}\otimes\mathbf{u})$——用瞬时快照即可训练，免除时间维数据。

## 知识点 8：误差度量与谱偏差

**论文位置**：Table 2/4/8–11；Section 3.1.2 热流通量讨论
**代码位置**：`DataLoss` 中 `e0 = sqrt(Σr²/ΣY²)`（相对 L2 误差）

- **相对 L2 误差**：$\varepsilon = \|\hat u - u\|_2/\|u\|_2$。当场的均值接近 0 时会失真放大 → 论文引入 **NMAE**（归一化平均绝对误差）。
- **谱偏差（spectral bias）**：神经网络倾向先学低频分量，DT-PINN 预测的热流（高频边界量）偏小且随机（论文 Fig. 9）；LT-PINN 因显式边界约束缓解了这一问题。
- 训练监控见 `checkpoint/loss_log.csv`：400k 步收敛到相对 L2 ≈ 0.27%，与论文 Table 4 (0.0027) 一致。

## 知识点 9：Section 3.4 从拓扑反演到目标驱动设计

**论文位置**：Section 3.4、Fig. 20–23、Table A.1
**代码位置**：本仓库未包含该算例；当前只能依据论文方法和计算设置分析

Section 3.4 是论文中唯一完整展示“没有内部测量数据、直接按工程目标生成拓扑”的算例。它将 $25D\times15D$ 流道中的48个直径为1的圆形 patch 作为设计变量，使均匀入口速度最终形成指定的正弦出口速度剖面：

$$
u_{out}(s)=\sin(2\pi s/15)+1,
\qquad Re=1.
$$

### 9.1 与前面反演算例的区别

| | Section 3.1–3.3 | Section 3.4 |
|---|---|---|
| 问题性质 | 依据稀疏场数据识别参考拓扑 | 根据目标生成可行拓扑 |
| 内部测量数据 | 有 | 无 |
| 真值拓扑 | 存在 | 不存在唯一真值 |
| 几何先验 | patch 类型及阵列约束 | 只保留圆形 patch，允许重叠 |
| 驱动力 | 场重建误差 | 出口目标剖面误差 |

“无拓扑先验”是指没有阵列间距、周期性排列等拓扑损失，并不意味着完全没有几何先验；圆的形状、尺寸和数量仍由设计者预先给定。

### 9.2 损失项角色重分配

| 损失 | Section 3.4 中的作用 |
|---|---|
| $L_p$ | 在约135万个配点上约束定常不可压 NS 方程 |
| $L_b$ | 48个圆表面的无滑移条件，共20,480个边界点 |
| $L_d$ | 承载入口速度、上下周期条件和出口目标速度剖面，共800点 |
| $L_t$ | 刻意不使用，允许圆自由聚集和重叠 |

这里的 $L_d$ 不再代表实验/仿真测量数据，而是“给定位置上的目标场值”这一统一损失形式。设计目标能写成逐点出口剖面，因此可以复用数据损失；对于最高温度、总阻力等积分或极值目标，应新增相应的可微泛函，不能机械地全部塞入 `DataLoss`。

### 9.3 论文计算设置

| 项目 | 设置 |
|---|---:|
| 网络 | 5层 × 64神经元，tanh |
| 优化器 | Adam，学习率 $10^{-4}$ |
| 训练 | 100,000 epochs |
| PDE配点 | $1500\times900$ |
| 边界点 | 20,480 |
| 目标/边界数据点 | 800 |
| 权重 | $\lambda_p=2\times10^3$，$\lambda_b=10^4$，$\lambda_d=10^4$ |
| 硬件 | 4 GPU |

48个随机分布的圆在训练后聚集到流道右下区域，形成阻塞下半流道的团簇，使上半区域加速、下半区域减速，从而实现目标出口剖面。显式圆心使结果可以直接重建为 CAD 并送入 CFD 验证。

### 9.4 Fig. 22–23 的关键教训：约束即所得

论文的独立 CFD 与 LT-PINN 在目标出口速度上接近，但压力和局部横向速度存在差异。主要原因不是目标没有达到，而是两种模型采用了不同的边界闭合：LT-PINN 在右侧指定目标速度且未给压力数据，CFD 则采用压力出口。

因此，LT-PINN 找到的是满足所有**显式约束**的自洽解，不一定是另一个边界闭合问题的逐点复现。工程使用时必须：

1. 列出所有已施加和未施加的边界自由度；
2. 区分“目标达成”与“完整场复现”两类验收；
3. 用独立求解器采用完全一致的边界条件复核；
4. 检查未显式约束的压力、通量和边界场是否出现非预期自由度。

### 9.5 对 LT-PINN 方法的证明范围

Section 3.4 支持以下结论：

- 无内部测量数据的目标驱动设计在 LT-PINN 框架中可行；
- 显式几何变量可在较大设计空间中与场网络联合更新；
- 生成结果可以转为 CAD/CFD 模型；
- 边界条件和目标的写法会决定解的物理闭合方式。

它并未证明高 Re、高 Ra、多材料共轭传热或辐射问题会自然稳定收敛，这些都属于超出论文算例的新扩展。
